# 儿童故事生产工作台｜半自动高效版

> 这是保留的旧工作台说明。新项目推荐使用根目录 `README.md` 中的 `story_agent.py` 全自动入口；旧工作台不会删除，便于人工接管或回退。

这是从老工作台独立复制出来的半自动版。老版目录保持不动：

```text
/Volumes/语苗计划/外置硬盘/New project
```

本版目录：

```text
/Volumes/语苗计划/外置硬盘/New project 半自动版
```

启动方式：

```bash
python3 workbench_semi_auto_app.py
```

也可以双击：

```text
run_workbench_semi_auto.command
```

## 核心思路

- 机器负责：建项目、识别素材、生成任务书、准备图生视频、生成片段、检查、登记、打包。
- 人工负责：达芬奇抠像、背景成片、主账号发布视频、必要时宝库号发布视频、外部朗读标注。
- 等待出图或图生视频时，工作台会提示可并行做的事项，减少空等。

## 术语

- 只使用“主账号”
- 只使用“宝库号”
- 不使用任何其他误称

代码内部变量可能仍叫 `library`，但用户可见文案统一为“宝库号”。

## 推荐素材放置

每个故事项目仍使用：

```text
故事剪辑：故事名/
  00_输入素材/
  01_分镜与图片/
  02_图生视频/
  03_背景成片/
  04_发布视频/
  05_发布物料/
  06_资料包/
  99_项目状态/
```

原始素材推荐放进 `00_输入素材`：

```text
{slug}_source.txt
{slug}_narration.wav/mp3/m4a
{slug}_greenscreen.mp4/mov
{slug}_music.mp3/wav/m4a
```

工作台也兼容识别文件名中的关键词：`原文`、`story`、`source`、`原声`、`narration`、`voice`、`绿幕`、`greenscreen`、`bgm`、`music`。

## 半自动主流程

1. 创建/更新项目，保存并识别素材。
2. 在右侧粘贴故事原文，按分镜换行，保存到项目。
3. 生成 Codex 出图任务。任务书会强制要求分镜文本使用原文，不改写、不浓缩。
4. 出图等待时，并行做配乐、发布视觉素材、达芬奇抠像准备、外部朗读标注。
5. 图片完成后，准备图生视频、写入旁白时长、生成视频片段并审核。
6. 视频片段完成后，优先在达芬奇手工合成背景成片。
7. 回工作台登记：
   - `story_no_subs_bgm.mp4`
   - `story_sales_subs_bgm.mp4`
   - `story_demo_voice_bgm.mp4`
8. 手工或机器生成主账号/宝库号发布视频，回工作台登记：
   - `主账号发布视频.mp4`
   - `宝库号发布视频.mp4`
9. 提前生成发布物料草稿。它不再强制等待两个发布视频都完成。
10. 登记外部朗读标注、A镜无人版和 PPT/图片素材。
11. 做资料包前置审查、正式打包、最终交付清单。

## 新增按钮

- `刷新半自动状态`：生成 `99_项目状态/semi_auto_status.md`
- `登记背景成片三版`：登记无字幕、有字幕、人声示范版
- `登记主账号发布视频`
- `登记宝库号发布视频`
- `登记A镜无人版`
- `登记外部朗读标注`
- `登记PPT/图片素材`
- `手工产物检查`：生成 `qa_manual_outputs_report.md`
- `提前生成发布物料草稿`：生成不依赖发布视频的 Codex 任务书

## 旧工作台发布物料规则

- 旧按钮仍可能沿用横版封面逻辑。
- 全自动 Agent 的正式交付契约是：主账号与宝库号各生成 `3:4`、`4:3`、`16:9`，共六张封面，并分别生成发布文案。
