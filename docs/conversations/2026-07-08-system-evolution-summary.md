# 2026 年 7—8 月系统演进摘要

本文是长对话的脱敏决策摘要，不是逐字聊天记录。原始对话可能含密钥、本机路径、账户信息和私人素材，不进入 Git。

## 起点

系统最初是半自动工作台：人工准备文本、图片、音乐和视频片段，再通过工作台执行时长、审核和合成。目标逐渐演变为由 Codex 接收一条绿幕原片并自主完成全套故事产品。

## 第一阶段：从工作台到持久 Agent

- 确立 Codex 为用户入口，工作台退化为故障驾驶舱。
- 建立 `story_agent.py`、registry、manifest、取消、恢复和 supervisor。
- 明确文件存在不等于 QA 通过。
- 建立默认预算、运行时限、磁盘和 CAPTCHA 安全阻断。

## 第二阶段：真实故事反馈驱动质量合同

《大象和蚂蚁》和《小老虎当评委》暴露出：肤色与 LUT、4K 发布、人物一致性、缺少角色单镜头、景别呆板、字幕与文稿污染、抠像裁切、尾帧黑块、资料包布局等问题。

由此加入：

- 视觉圣经、分镜设计和角色一致性；
- 原生构图与抠像候选审核；
- 发布画框、尾帧和黑块 QA；
- 语义合同，区分标题、主持人口播、正文、道理和结尾；
- 产品标注、PPT、封面与资料包独立审核。

## 第三阶段：快速入口与并行 DAG

用户可提供已经剪辑、还原 LUT、确认文本和确认字幕的输入，跳过不必要的前处理。系统引入 33 阶段 DAG，使视觉、配乐和发布资产在项目初始化后并行，并用写集合与资源容量防止冲突。

## 第四阶段：模型分工

讨论过 Sol、Terra、Luna 和 DeepSeek 多层协作，但最终决定先采用两个生态位：Sol 指挥官、Luna 工人。DeepSeek 或 Terra 只作为同一工人位置的替代实验，不常驻增加复杂度。

GPT-5.6 具备原生多模态，视觉审核不再依赖为旧文本模型准备的外部视觉桥接服务。

## 第五阶段：外部工具变化

- Suno 使用 Ego Browser 登录状态和自定义 Duration。
- 视频改为供应商适配器下的 Grok Video 1.5，支持逐镜 1—15 秒、720p、16:9。
- 探索 Palamary Pro 作为可视化时间轴，但正式确定性合成仍以 FFmpeg 为基线。
- 视频、音乐供应路径均被视为可替换适配器，不写死为永久唯一方案。

## 《小壁虎借尾巴》验证

该故事验证了跨镜头状态机：完整尾巴、断尾转换、长期缺尾、重新长尾。系统成功交付，但生产约耗费用户观察的 18 小时和大量周额度，暴露出返工放大、重复上下文、调度黑箱、人工恢复不计时和成本币种错误。

## 当前共识

1. 不推翻现有可靠合同。
2. 下一步先解决可观察性、增量返工、上下文和账单。
3. 模型档位通过基准实验决定，不凭单次印象。
4. GitHub 私有仓库保存代码、文档、ADR 和脱敏复盘；大媒体、原始对话和密钥留在仓库外。
