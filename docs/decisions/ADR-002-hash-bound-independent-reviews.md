# ADR-002：哈希绑定的独立审核

- 状态：已采用
- 日期：2026-07—08

## 背景

过去出现过文件存在但内容错误、审核对应旧产物、模型生产者自述完成、发布视频尾帧或画框异常等问题。

## 决策

所有关键审核使用标准 artifact bundle，记录 SHA-256，并由独立模型上下文审核。通过条件为分数至少 85、关键错误为空、bundle current、review 与 bundle 哈希匹配。

## 结果

可靠性明显提高，能够防止旧审核冒充新产物。代价是证据包构建、视觉抽帧、文档渲染和重复哈希增加了时间与上下文。

## 优化方向

保留合同，但改为内容寻址缓存、变更镜头增量审核、相邻镜头连续性审核和按需证据加载，而不是每次重读整包。
