# Story Agent v3.6.2-canary.1（2026-08-25）

本版本针对《七色花》后台短测在正式生图前长时间停留、合同与视觉小样互相反复重做的问题，缩短前置链路，同时保留合同、独立审核、哈希绑定和原产物保护。

## 行为变化

- `story_contract` 只生成文本和 JSON，不调用 ImageGen，也不把视觉小样塞进合同审核。
- 合同审核拒绝时必须声明 `retry_contract_sections`；最多进行一次定向修订，Runtime 会恢复所有未获准修改的合同节。
- 新项目的角色和风格共用一张母版；历史项目已有独立风格/角色小样时继续复用，不强制重生。
- 长状态序列只抽取初始、中间、最终三个独立代表状态，每张只画一个状态；完整 F0～Fn 序列继续由结构化合同约束正式分镜，不再要求一张总表同时画完。
- 视觉小样总尝试次数上限为三次；同类失败第二次出现必须切换到更简单的单状态/单主体策略，第三次失败后停止。
- 视觉小样生产者只接收逐图 `relevant_contract`，不再接收整份视觉合同作为生成要求。
- Dashboard 区分基准估算、倒计时和“原估算已过期”，并解释旧 `passed` 记录为何变为 `stale`。

## 模型与运行策略

- 常规执行继续使用 Luna High。
- 独立合同/质量判断继续使用 Sol Medium。
- 默认运行时限保持 10 小时；项目可显式覆盖为 8 小时。

## 验证

- 完整测试：`552` 项通过。
- CLI 帮助与 Python 编译检查通过。
- 本版本提交后才允许现有项目通过显式 code-binding migration 继续运行；不会静默跨提交恢复。
