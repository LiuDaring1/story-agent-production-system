# Story Agent v3.6.2-canary.2（2026-08-25）

## 七色花实测修正

- `stop-after-stage` 现在会把 DAG 裁剪为目标门禁及其传递前置阶段；图片短测不再提前启动音乐、发布或资料包分支。
- 合同生成与下游计划使用同一份实际逐行语义源。
- 固定的 `semantic_kind × artifact` 缺项由 Runtime 只补缺项，保留模型已有选择；高分审核不能再把缺失映射放行到下游。
- 若旧合同已审核后才发现缺项，Runtime 归档旧合同哈希、审核与锁，补齐固定映射后强制重新独立审核，不重写整份合同。
- 合同提示不再要求模型枚举重复的固定映射矩阵，减少无效结构化推理。

## 验证

- 完整测试：`554` 项通过。
- 七色花 canary 复现并覆盖了“合同 97 分但缺少 host_intro/demo_subtitles”以及“有界 DAG 提前启动音乐分支”两个问题。
