# Story Agent v3.6.2-canary.5（2026-08-25）

## 视觉小样局部返工改为母版引用式纠偏

- 视觉审核矩阵同时接受简式 `evidence` 与完整的 `observations + conclusion` 证据结构，不再因字段表达差异误报整批证据缺失。
- `contract_adherence` 可从 `relevant_contract` 的合同路径确定覆盖范围，不再要求审核模型重复写另一套维度名称。
- 审核失败必须给出明确 `sample_id`；无法定位失败小样时直接阻断，禁止退化为全量重画。
- 局部重试保留审核逐图修订指令，并把上一版失败图作为定向编辑参考，而不是仅凭文字重新抽样。
- 尺度小样必须引用最新角色母版；有限道具的中间/末态必须引用已通过的同实体母版。母版与派生图同轮返工时按依赖顺序生成，不并行独立抽奖。
- 失败小样仍保存在 `visual_samples/rejected`，引用路径和 SHA-256 写入重试收据；中断恢复后可以继续使用，不丢失返工上下文。
- 视觉小样总尝试上限仍为三次；重复失败会切换生成策略，不无限沿用同一提示词。
