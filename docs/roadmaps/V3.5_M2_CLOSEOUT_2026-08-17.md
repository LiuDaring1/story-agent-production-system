## 质量链事实

1. **Story Contract 是唯一事实源。** M2 的语义计划、小样计划、动作计划、keying preset、Demo/Release geometry、封面血缘和产品内容 manifest 都是审核合同的派生产物，并绑定 projection/hash/version。
2. **创意与确定性职责分开。** ImageGen/视频模型/独立多模态审核处理创意和语义判断；Logo、文字、坐标、安全区、来源 currentness、provider provenance 和 hash 由代码验证。
3. **Product/Demo 早于 Release。** `product_package_review` 是 `release_preview` 的依赖；required_v1 Release 必须读取 current 的最终 Demo presenter geometry receipt，不能自行重算已批准 geometry。
4. **失效粒度仍为模块族级。** 合同 section/projection 或上游资产变化会让真正绑定它的计划、receipt、render/package manifest stale，但尚无完整逐镜头/逐页依赖图。
5. **Legacy 不伪造新审核。** V3 历史项目只在 Runtime 生成并复验 eligibility receipt 时 passthrough；新任务和失败任务不能靠手改 manifest 降级。

## 当前 38-stage DAG 摘要

权威顺序位于 `story_agent_runtime.py`。主链为：素材 1—5 → 合同 6—7 → 语义/视觉前置 8—10 → 视觉/视频 11—19 → 音乐 20—23 → 横屏汇合 24 → 发布资产 25 → 产品与最终 Demo 26—30 → 发布视频 31—34 → 发布物料 35—36 → 交付 37—38。

M2-Z 增加纯确定性测试，固定检查：38 阶段唯一、依赖闭合且无环、依赖一定前置、estimate/branch/write-set 元数据覆盖完整，以及 `release_preview` 必须依赖 `product_package_review`。
