# 完整动态 PPT

输入必须是已经生成并通过机器完整性检查的完整故事镜头。不要为 PPT 再次调用视频生成模型，也不要把镜头截短或转换成 GIF。

## 四种播放壳

- 含字幕自动版、无字幕自动版。
- 含字幕控场版、无字幕控场版。

四种版本共用相同的静音视频代理：H.264、1280×720、`yuv420p`、无音轨。每页对应一个完整镜头，片头和寓意卡使用其既有动态卡片或完整停留时长。

- 自动版：进入页面自动播放，按视频实际时长自动翻页，同时保留提前按键翻页。
- 控场版：进入页面自动播放，播完停在末帧，不自动翻页；返回页面时从头播放。
- 背景音乐作为共享目录中的独立 MP3 跨页连续播放。自动版不循环；控场版播放不足时循环。人工翻页不重启音乐，也不重新同步音乐时间轴。
- 含字幕版使用既有 PPT 单行字幕排版；无字幕版不得保留隐藏字幕对象。

## 产物与 QA

- `story_ppt_plan.json` 逐页记录镜头 ID、源视频和代理视频哈希、实际时长、字幕、播放模式和背景音乐哈希。
- 默认让四个 PPTX 引用同一 `PPT动态素材` 目录并整体 ZIP 交付；只有 WPS 干净环境验证失败时才使用 `--dynamic-ppt-embed-media` 切换为 PPTX 内嵌媒体。
- 使用 JavaScript Artifact Tool 构建每页 poster、字幕和版式，再写入视频媒体关系、自动播放和翻页计时。
- 交付前渲染检查每一页，并在 WPS 实机测试：自动连续播放、提前翻页、返回重播、控场末帧、字幕、跨页音乐和解压后的媒体路径。
